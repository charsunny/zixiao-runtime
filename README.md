# zixiao-runtime

子晓纪 macOS 的构建时/下载时构件仓 (公开): sherpa-onnx 静态运行时 XCFramework、TTS 模型合包。
源码与出处说明见 [charsunny/zixiao-desktop](https://github.com/charsunny/zixiao-desktop) (私有) 内
`Packages/ZixiaoLocalInference/README.md`。

## Releases

- `sherpa-onnx-v1.13.8`: `SherpaOnnx.xcframework.zip` (官方静态库合并, Apache-2.0) 与
  `matcha-icefall-zh-baker-vocos.tar.bz2` (官方声学模型 + vocoder 原样合包)。
